# Icon pack licences

Only open-source packs from Iconify JSON (`@iconify-json/*`, dev dependencies of the repo root). Nothing proprietary, no AWS set.
Pack data is generated by `pnpm gen:icons` into `packages/core/src/icons/*.json`.

| Prefix | Pack | Licence | Source |
|---|---|---|---|
| `lucide` | Lucide | ISC | https://github.com/lucide-icons/lucide/blob/main/LICENSE |
| `si` | Simple Icons (brand logos, monochrome) | CC0-1.0 | https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md |
| `carbon` | Carbon icons (IBM; cloud/infra glyphs, monochrome) | Apache-2.0 | https://github.com/carbon-design-system/carbon/blob/main/LICENSE |
| `devicon` | Devicon (colored tech logos) | MIT | https://github.com/devicons/devicon/blob/master/LICENSE |

Icons using gradients, opacity, transforms, clip paths or `<use>` are left out by `gen:icons` (the player draws flat solid paths only), so a few logos (e.g. Python) are missing.

Brand logos remain trademarks of their owners; Simple Icons are used here only as monochrome identifiers of the named technology.
